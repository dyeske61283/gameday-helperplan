# Prototype Link Access and Selected Member

**Status:** accepted

Until authentication exists, a valid shared plan link is the access boundary and grants full plan read/write access. A person selects a member ID for the prototype cockpit; that selection is persisted locally for convenience, can be changed freely, and is not treated as authentication or authorization. Sensitive administrative actions and an exceptional admin-mode activation are intentionally deferred rather than simulated with unreliable identity assumptions.

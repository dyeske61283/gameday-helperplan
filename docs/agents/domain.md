# Domain Docs

This is a single-context repository.

## Before Exploring

Read:

- `CONTEXT.md` at the repository root.
- Relevant ADRs under `docs/adr/`.

Read only ADRs related to the area being changed.

## Vocabulary

Use the terminology defined in `CONTEXT.md` for issue titles, plans, tests, and implementation output. Do not introduce synonyms for terms explicitly avoided there.

## Conflicts

If a proposed change conflicts with an ADR, call out the conflict explicitly instead of silently overriding the decision.
